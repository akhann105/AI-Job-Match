# AI Job Match

An AI and Data Science project that analyzes tech job postings to understand which skills are most common in the job market.

## About the Project

I started this project to improve my skills in Python, data analysis, and machine learning while building something useful for students and job seekers.

The goal is to eventually create an application that compares a user's resume with job descriptions, recommends matching jobs, and identifies skills they could improve.

## What I've Built So Far

- Loaded and cleaned a dataset of 1,020 tech job postings.
- Used Python and Pandas to analyze job descriptions.
- Built a skill detection function using regular expressions.
- Identified and ranked commonly mentioned technical skills.
- Created a bar chart showing the top 10 skills.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Regular Expressions (Regex)
- Git and GitHub

## Dataset

Tech Jobs Dataset 2026, available on [Hugging Face](https://huggingface.co/datasets/Sundaydream/tech-jobs-dataset-2026).

## Future Plans
